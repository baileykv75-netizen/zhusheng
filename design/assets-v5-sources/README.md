# V5视觉资产母版

本目录保存“筑生”V5第一轮视觉资产的无文字PNG母版。网页不直接加载本目录文件，而使用 `public/assets/v5` 下的压缩版本。

## 几何基准

- 建筑场景以 `public/assets/v4/building-stage.webp` 为结构和机位基准。
- 卫生间场景以 `public/assets/v4/bathroom-stage.webp` 为构件和镜头基准。
- 1602始终位于建筑右侧中高层，立管沿右侧竖向贯通。
- 卫生间阀门位于左上检修盒，支管接头位于左中，湿度传感器位于其下，微流量计位于底部。

## 生成方式

素材使用 Codex 内置 ImageGen 生成或基于V4基准图编辑，提示词统一要求：锁定建筑或卫生间几何、相机和关键构件；不生成文字、编号、UI、人脸和水印；保持黑银灰、低饱和青色水系统及克制工程可视化风格。

阀门关闭状态以开启状态为编辑目标，仅改变阀门机械状态、状态灯和局部流量表现。证据图采用现场手机或检验设备拍摄风格，与全屏建筑可视化区分。

## 导出规则

- 核心场景：1600x1000 AVIF/WebP。
- 移动场景：720x960 AVIF/WebP。
- 证据图片：1200x900 WebP。
- 占位图片：64x40模糊WebP。
- V4资产保留不覆盖，便于快速回退。
