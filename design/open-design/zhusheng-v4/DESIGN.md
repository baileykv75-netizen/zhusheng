# 筑生 V4 设计系统

## 设计命题

筑生不是一个通用后台，而是一栋建筑持续工作的数字生命舞台。界面把建筑模型放在视觉中心，只在当前任务需要时叠加主任务、必要依据和安全动作。

## 视觉来源

- Open Design Homepage：空间运动与沉浸式产品叙事。
- Web Prototype Taste Soft：精细材质、克制层级和高质量留白。
- Autodesk Forma / Bentley iTwin：模型主导、上下文操作。
- Siemens Building X：事件、工单和设备动作的专业表达。

参考用于建立设计原则，不直接复制模板或组件。

## 核心规则

1. 一套共享舞台，四个角色只切换镜头和任务层。
2. 每个视口最多同时保留三个信息面。
3. 企业红只表示决策、风险和当前步骤。
4. 管线青只表示水系统、传感器和空间定位。
5. 建筑与构件必须是首屏视觉主体，不能退化为卡片背景。
6. AI只以运行模式、整理结果和可追溯协作链出现，不使用拟人头像。
7. 高影响设备动作必须进入独立人工授权层。

## 构图

- 桌面：72px品牌侧轨、浮动项目栏、全屏建筑场景、右侧任务档案。
- 平板：保留侧轨，收窄镜头和档案，生命周期信息压缩。
- 手机：上半屏为静态空间镜头，下半屏为单列任务工具，底部四入口导航。
- 演示：底部电影时间轴连接七步，不遮挡关键操作。

## 资产策略

- 所有建筑视觉均为脱敏演示模型，不暗示真实项目成果。
- PNG母版位于 `masters/`，公网只加载AVIF/WebP及移动裁切。
- 主图加载失败时回退到原建筑剖面素材，舞台不得空白。

## 动效

- 场景响应：最大6px视差，480ms回正。
- 面板揭示：240ms。
- 按钮反馈：140ms。
- 水流只在事件或口述活跃时出现。
- `prefers-reduced-motion` 下关闭视差和循环动效。
