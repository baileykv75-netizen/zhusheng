# 筑生 V5 连续视觉叙事

## 设计命题

V5不以增加图片数量为目标，而是让镜头本身解释建筑全生命周期智能体如何工作：

`建筑总览 -> 16层空间 -> 隐蔽施工 -> 完成面异常 -> 建造记忆透视 -> 阀门动作 -> 维修验证 -> 集团反馈`

## 场景原则

- 同一建筑图层共享建筑轮廓、相机和1602位置。
- 建造、异常、设备动作和维修验证共享卫生间构件关系。
- 住户首先看到完成墙面异常，诊断后才局部透视隐藏管线。
- 人工授权切换到阀门特写，开闭状态以对齐图片交叉淡入。
- 第七章先确认维修有效，再把证据写回集团知识网络。
- 全屏图不包含文字和UI，编号、状态与审计信息由网页叠加。

## 运行规则

- 首页初始只加载建筑总览；稳定后空闲预取专业图层和施工场景。
- 演示页面只预取当前故事下一阶段需要的场景。
- 目标图片解码完成后才切换；失败时保留旧场景。
- 热点由当前 `SceneId` 派生，与图片在同一状态更新。
- 证据缩略图按需懒加载，查看器不跳页，支持 Escape 关闭并恢复焦点。
- 移动端使用独立裁切和焦点，关闭视差并保持主要构件可见。

## 第一轮资产

核心新增：16层空间剖切、设备感知、完成面潮湿、阀门开启、阀门关闭、维修验证。

证据新增：接头近照、压力复核、墙面潮湿、水表状态、维修验收。

集团项目群、建筑给排水和施工剖面继续使用V4几何基准，经V5目录重新压缩和版本化。
