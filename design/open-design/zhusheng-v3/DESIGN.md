# Zhusheng V3 Design System

> Architectural editorial calm for a building lifecycle operating product.

## Design posture

Zhusheng should feel like an architectural studio presenting a precise working model, not a dense monitoring wall. Each viewport has one dominant task. Supporting evidence is available through disclosure and quiet side context instead of being permanently expanded.

- Canvas: mineral off-white with white working surfaces.
- Geometry: square, precise, and limited to 4px radii.
- Hierarchy: one large entry point, one supporting layer, one metadata layer.
- Accent discipline: corporate red marks the current action or risk; water cyan marks water-system data only.
- Depth: created by whitespace and contrast, not shadows, gradients, or nested cards.

## Layout

- Desktop content max-width: 1440px.
- Desktop page gutter: 48px; tablet: 28px; mobile: 18px.
- Base spacing: 8px with 16/24/32/48/64px chapter gaps.
- Desktop header: one 64px bar containing identity, navigation, project context, runtime, and demo entry.
- Demo dock: 52px, centered, and never full viewport width.

## Typography

- UI family: Noto Sans SC, Microsoft YaHei, Arial, sans-serif.
- Numeric/code family: Cascadia Mono, Consolas, monospace.
- Desktop page title: 36-40px, weight 600, tight line height.
- Section title: 20-24px, weight 600.
- Body: 14px minimum; metadata: 11-12px minimum.
- Avoid all-caps English decoration. Codes may use restrained monospace labels.

## Components

- Primary action: solid corporate red or ink, 48-52px target height.
- Secondary action: text/icon on a quiet neutral surface.
- Inputs and safety panels may use borders; layout sections should not.
- A disclosure summary must state what is hidden and its evidence count.
- Status colors communicate state only and are never decorative.

## Anti-patterns

- No dark full-height sidebars, glowing nodes, gradient technology backgrounds, glass panels, or card grids.
- No body copy below 13px and no metadata below 11px.
- No two simultaneous primary actions above the fold.
- No permanently expanded event timeline, evidence register, and action panel in the same viewport.
- No invented claims or decorative English product slogans.
