# 筑生两分钟介绍视频脚本

## 录制原则

- 画面以真实产品录屏为主，不使用PPT。
- 右上角始终能看到“AI在线”或“演示回退”。
- 所有设备动作必须拍到人工授权界面。
- 字幕与旁白一致，关键证据编号在画面中可见。

## 分镜与旁白

### 0–12秒｜产品定义

画面：建筑生命主页，建筑剖面与生命记忆完整度。

旁白：

> 一栋建筑可以使用几十年，但建造知识往往在交付时失忆。筑生让每栋房子从开工第一天就拥有一个会成长的建筑总智能体。

字幕重点：从开工第一天，到入住每一天。

### 12–28秒｜总体架构

画面：一楼一脑、一事一专区域和建筑生命线。

旁白：

> 它保存建筑的长期记忆，协调专业智能体，并把建造证据、空间关系、传感器和设备连接在同一个建筑身份下。

字幕重点：一个总智能体，贯穿建造、交付和入住。

### 28–48秒｜工友留下记忆

画面：启动引导演示，完成步骤1和步骤2。

旁白：

> 建造时，工友只需扫码、口述并拍照。工友服务智能体整理记录，品质智能体核验证据，让少填一张表，变成多留一份匠心。

字幕重点：语音整理；证据核验；品质贡献留痕。

### 48–82秒｜跨阶段联合诊断

画面：完成步骤3至步骤5，展示湿度曲线、证据编号和86%可信度。

旁白：

> 入住后，1602卫生间出现持续湿度异常。总智能体没有直接下结论，而是调用品质和建筑健康智能体，查询施工证据，并请住户补充停水后的水表状态和墙面照片。

字幕重点：不凭一次异常下结论；诊断依据可追溯。

### 82–102秒｜授权与行动

画面：关阀授权、设备结果和工单。

旁白：

> 当疑似漏点被定位到具体接头后，系统提出局部关阀建议。只有获得住户明确授权，设备具身智能体才会执行，并向物业生成包含位置、材料和检修建议的精准工单。

字幕重点：人在回路；设备动作全程审计。

### 102–114秒｜集团反哺

画面：集团管理端的协作轨迹、工单和企业知识反馈。

旁白：

> 维修后，系统继续验证湿度回落，并把真实原因写回建筑记忆，形成下一批MiC模块可复用的工艺建议。

字幕重点：建造一栋楼，积累一类经验。

### 114–120秒｜收束主题

画面：闭环完成状态和项目名称。

旁白：

> 筑生，让建造时的每一份匠心，成为入住后的长期守护。为人民建好房，为工友谋幸福。

字幕重点：筑生：一栋房子一生的AI智能体。
