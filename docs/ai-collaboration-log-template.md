# 人机协同履历证据模板

本文件用于持续记录团队如何使用AI完成作品，最终按主办方模板整理为PDF。不得补造未发生的协作过程。

## 基本信息

| 字段 | 内容 |
|---|---|
| 团队成员 | 待填写 |
| 人员职责 | 待填写 |
| 使用的AI工具或模型 | 待填写 |
| 使用阶段 | 需求 / 产品 / 开发 / 视觉 / 测试 / 文档 |

## 单次协作记录

| 字段 | 内容 |
|---|---|
| 日期 | YYYY-MM-DD |
| 任务目标 | 这次需要解决什么问题 |
| 人类输入 | 专业规则、约束、数据和判断 |
| 代表性提示词摘要 | 保留关键要求，不包含密钥和隐私 |
| AI输出 | 方案、代码、视觉或文案的简要说明 |
| 人工修改 | 接受、修改或否决了什么，为什么 |
| 验证方式 | 测试、截图、评审或专业核验 |
| 最终结果 | 对应文件、版本或界面 |
| 证据路径 | 截图或记录文件名 |

## 本作品建议保留的证据

1. 从单点案例收束为建筑全生命周期总智能体的方案讨论。
2. “一个产品、四个视角、一条闭环”的产品形态决策。
3. 建筑剖面视觉生成及人工筛选记录。
4. AI兼容层、稳定回退和设备安全边界的代码与测试。
5. 桌面端、移动端和七步引导演示的浏览器验证截图。
6. 被否决方向：实体机器人、第二案例、完整三维BIM和无边界自动控制。

## 表述边界

- 产品内AI：负责口述整理、解释生成和任务建议。
- 确定性程序：负责风险等级、授权、设备动作和事件关闭。
- 创作协同AI：协助团队进行方案推演、代码、视觉、测试和文档。
- 人类团队：负责主题判断、建筑专业规则、安全边界、事实核验和最终取舍。
