# 筑生参赛提交材料底稿

## 作品标题

筑生：一栋房子一生的AI智能体

## 作品简介

建筑使用几十年，建造知识却常在交付时失忆。筑生为每栋建筑创建贯穿设计、建造、交付与入住的总智能体：工友通过语音和照片留下可信施工记忆；入住异常发生后，专业智能体基于证据联合诊断，在住户授权后协调设备与物业，并将维修结果反哺下一项目。作品以卫生间渗漏跑通一条可交互闭环，探索数字建造向建筑具身智能延伸。

## 说明文档内容结构

按主办方PDF模板排版，建议8至10页：

1. 封面：项目名称、副标题和主题。
2. 核心矛盾：建筑长期存在，建造知识在交付时失忆。
3. 主题价值：为人民建好房、为工友谋幸福。
4. 总体架构：一楼一脑、一事一专、生命记忆和具身执行。
5. 生命周期机制：建造留痕、交付继承、入住服务和集团反哺。
6. 产品样机：四个视角、两种模式和七步闭环。
7. 可信AI：证据引用、运行模式、规则边界和人工授权。
8. 公司价值：数字建造延伸、MiC服务入口、维保提效和企业知识资产。
9. 试点指标：记录耗时、证据完整率、定位时间、复发率和建议采纳数。
10. 边界与路线：当前模拟范围和未来真实项目接入方式。

所有试点指标均表述为验证目标，不写成已经取得的成果。

## 文件检查

- 说明文档：PDF，不超过30MB。
- 介绍视频：MP4，不超过2分钟，不超过500MB，带字幕。
- 人机协同履历：PDF，不超过10MB，按主办方模板合并团队成员信息。
- 作品本体：源码、一键启动脚本、README、截图、样例数据和测试。
